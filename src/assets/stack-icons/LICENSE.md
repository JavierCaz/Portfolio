# Stack icons

Brand marks used to label the technologies in the stack section. Each logo is a trademark of its owner.

- Most icons: [Simple Icons](https://simpleicons.org) v16.33.0, CC0-1.0.
- `sql-server.svg`, `aws.svg`, `azure.svg`: [Devicon](https://devicon.dev) v2.17.0, MIT. Fills stripped to `currentColor`.
- `codex.svg`: original terminal glyph (no official monochrome mark available).
